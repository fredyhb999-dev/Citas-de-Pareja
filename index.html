Bienvenidos 💛

Conectemos tu base de datos (una sola vez).

  1. Entra a console.firebase.google.com con tu Google.
  2. Agregar proyecto → nombre → sin Analytics → Crear.
  3. Menú → Firestore Database → Crear base de datos → Producción → Habilitar.
  4. Pestaña Reglas → permite lectura y escritura → Publicar.
